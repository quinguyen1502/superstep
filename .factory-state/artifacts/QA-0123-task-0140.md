- Criterion: an unpublished chat (disabled, or `studio`) returns `CHAT_NOT_PUBLISHED`, and the response says nothing
  about the workflow.

- Criterion: two anonymous clients each see only their own sessions; a forged token or another visitor's session id
  returns not found.
  - Result: pass.
  - Evidence: `test_each_anonymous_visitor_sees_only_their_own_chats`.
    - B's list is empty, and B reading A's session gives `CHAT_SESSION_NOT_FOUND`.
    - A forged signature starts a new visitor with no sessions.

  create a session, and its `owner` is that user.
  - Result: pass.
  - Evidence: `test_signed_in_chats_need_an_account_but_not_the_run_right`.
    - An anonymous client gets 401 `CHAT_SIGN_IN_REQUIRED`, while the page itself still loads with
      `signed_in: false`.
    - A guest account creates a session whose `owner` is the guest.
    - A third account sees no sessions and cannot read the guest's.

  - Result: pass.

    - A taken slug gives 409 `CHAT_SLUG_TAKEN`.

    - Five bad origins give `CHAT_EMBED_ORIGIN_INVALID`: plain http, a path, ftp, user information, and not a URL.
    - Origins are lower-cased and their trailing `/` removed.

  - Result: pass.
