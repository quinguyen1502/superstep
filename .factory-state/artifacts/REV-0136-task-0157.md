## Standards And Architecture Alignment

- DEC-0069 decision 1: a missing `parallel_tool_calls` stays on. Explicit false forces a wave of one and sends the provider flag. OpenAI and OpenAI-compatible `bind_tools` get `parallel_tool_calls=False`. Anthropic sets `tool_choice.disable_parallel_tool_use`. Other providers are unchanged. The sequential test returns three calls from the model double while the flag is false, and the spans do not overlap.
- Decision 2: `STUDIO_AGENT_PARALLEL_TOOLS` defaults to 4. An empty or non-integer value is 4. Other integers clamp to 1..8. The clamp is written as 8 in `core/config.py` so that module does not import the engine. `MAX_CALLS_PER_ROUND` is still 8.
- Decision 3: eight slots `A/__tool/1` .. `A/__tool/8`, join `A/__join`, `Send` of only the pending prefix, unlabeled model-to-slot edges for the validator. Each slot writes `agent:<id>#<n>`. The join appends messages and steps in index order and clears the channels. `agent_join` is not in `SIDE_EFFECT_TYPES`. `step_budget` counts a slot and a join per call at cap 1.
- Decision 4: the ledger key is the slot id. The same tool with the same arguments records two keys. `checks.tool_ran` uses `agent_of_step`, so `A/__tool` and `A/__tool/N` both match.
- Decision 5: the three-call test has one checkpoint whose nodes are the three slots, then a later checkpoint for the join, and no checkpoint of a proper subset of those slots.
- Decision 6: a raised tool becomes `status: error` inside the slot. The other two calls finish, and the steps stay in the model's order.
- Decision 9: two named tools return `mock_call_1` and `mock_call_2` in tool-list order. "Where is my order B200?" stays one desk.
- DEC-0009: the engine change does not import FastAPI or run SQL. `chat_session_service.steps_of` hides `agent_join` so an existing one-call chat stays `[agent_model, agent_tool, agent_model]`. That is one filter in the service, which already owns chat steps.
- No new dependency and no migration.
