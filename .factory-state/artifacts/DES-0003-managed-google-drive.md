Reuse Settings → MCP → Managed connection. Add Google Drive to the existing adapter selector; show a labelled allowed-folder ID and one write-only Google credential JSON field. Setup help describes authorised-user refresh credentials versus service-account/Shared Drive creation. No auth wizard or new settings area. Stored secrets stay blank on edit, with the existing keep-secret hint.

Discover four schema-driven tools in current MCP nodes and Agent slots. Operators see bounded metadata/text/creation receipts in the existing trace and statuses in Recent operations. Unknown creation offers the existing read-only check, never an upload-again button. Resource scopes and typed-name connection deletion retain current controls.

Use shadcn/theme tokens and en/vi text. JSON secret field uses existing Textarea and help; preserve keyboard/label/focus behavior and wrapping on narrow views. Browser screenshots cover create/edit/discover/use/confirmed and uncertain state in en/vi and light/dark with synthetic credentials only. Documentation explains folder access, Shared Drive storage rules, limits, marker preservation and external edits.
