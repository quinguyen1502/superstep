### Non-Blocking

- The split was generated from line ranges of the old `Editor.tsx`, so the JSX of the header and the four panels is unchanged text. `useStudio` holds the old `Studio` body; panels read it through `StudioContext`. It returns 92 bindings instead of all 125 locals.
- Three behaviour-neutral changes came with the split: the node context menu's Copy/Cut now go through the same `keep` path as the keyboard copy (`copyIds`); the `⋯` tooltip state is local to `EditorHeader`; the unsaved badge uses the existing `isDirty()` instead of repeating its expression.
- `useLoadWhen` and `useOnChange` (`lib/use-when.ts`) replace 15 effects. `useLoadWhen` keeps the old timing (an effect after `open` turns true or the key changes) and reads the latest props through `useEffectEvent`. `useOnChange` resets local state during render instead of one effect later; the dialogs it touches render the reset values on the same frame.
- `credentials-dialog` resets on close through `useLoadWhen(!open, reset)`; it also runs once on mount while closed, as the old effect did.
- `use-graph-history` moved from a render-time ref to state updated during render. `push` returns the same object when nothing changed, so the update settles in one pass.
- `versions-dialog` now also refetches the diff when `wid` changes (it was missing from the deps).
- Hooks moved out of component files: `useConfirmDelete` → `components/use-confirm-delete.tsx`, `useAction` → `components/approvals/use-action.tsx`, `useSlots`/`slotKey`/slot types → `components/approvals/slots.ts`, `ErrorAlert` → `components/approvals/error-alert.tsx` (re-exported from `channel-parts`), `ThemeToggle` → `components/theme-toggle.tsx` (`lib/theme.tsx` → `lib/theme.ts`). All importers updated.
- The three shadcn files keep their `cva` variant exports with an inline `oxlint-disable-next-line` and a reason.
