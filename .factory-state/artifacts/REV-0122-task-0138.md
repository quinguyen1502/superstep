### Fixed During Review

- **A waiting mark left on the canvas.** The trace screenshot showed the supervisor node still "waiting" after its run
  had moved on, because reopening a run replays the log but did not touch the canvas marks. `openRun` now turns
  waiting marks to done when the run it opens is no longer waiting. This is a one-line UI fix, kept here because the
  screenshots found it.
- **Out-of-date comparison text.** The visual builders page still said the Agent node had no TypeScript export
  (shipped in TASK-0125). The sentence is rewritten for the supervisor pattern.

### Non-Blocking

- **Same facts in both languages.** Every new section exists in en and vi with the same content. The vi text uses the
  glossary rows added in TASK-0136 ("công cụ workflow", "run được gọi", "kết quả").
- **The inbox name in the screenshot** reads "Support team › Support team · Refund desk": the template names its
  helpers after the supervisor. This is accurate, if long; the docs example uses the short form.
- **Claims match the code**:

  - the export behaviour;
