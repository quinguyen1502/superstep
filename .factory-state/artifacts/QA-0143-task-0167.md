## Residual Risk

- The new secret is stored on `cli_devices.secret` until the first poll. A database copy in that window contains it. DEC-0071 asks for that one-time handoff.
- There is no rate limit on starting a device or approving a code. The user code is 8 hex characters. Approving a guessed code issues a token for the account that is signed in, and only the CLI holding the device code can read it.
- If `GET /api/me` fails after the secret is taken, the CLI does not write `cli.json` and the server token remains until it is revoked by name.
- Two concurrent creates of the same name can both pass the check. The acceptance tests are sequential.
