## Findings

### Blocking

### Non-blocking

- Security: the type is read from the bytes and SVG is refused, so the public page cannot be made to serve script.
  The image is sent with its own type and `nosniff`. The size is checked before and after decoding.
- The settings are written before the logo row. If the second write failed, the page would point at a missing logo,
  get a 404 and show the first letter. Acceptable.
- The image's pixel size is not checked. A 256 KB PNG can still be very large when decoded, which costs the visitor's
  browser memory but nothing on the server. Can come later with a size check.
- A public logo is cached for good under its `?v=` address. After the chat is unpublished, a browser that already
  had it keeps it in its cache. It is only an image the builder chose to publish.
- The owner's review during the task: the logo is a square with rounded corners, the welcome block is centred, and the
  widget's bubble keeps its chat icon. All done.
