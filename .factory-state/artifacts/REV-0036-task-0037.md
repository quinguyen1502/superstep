## Findings

### Blocking

- No blocking findings.

### Non-Blocking

- The sticky is saved in the workflow `nodes` array with type `note`, so its position and text round-trip. The palette, the command palette, and the node card do not present it as a graph node. The engine skips it.
- While the sticky's text field is focused, Delete and Backspace edit the text. The canvas shortcut does not remove it until focus leaves the field. The context menu item Delete note removes it. This matches the editor rule that a text field keeps its own keys.
- An imported workflow was not opened. The canvas menu does not offer Add note when the graph is not editable.

## Standards And Architecture Alignment

- Validation and compile stay in the engine. The engine does not import FastAPI. No new route and no new error code.
- The sticky uses shadcn `Textarea` and the `--node-note*` tokens. No hard-coded colour and no left accent bar. Graph nodes still take their classes from `META`.
- Strings for Add note, Delete note, the placeholder, and the hint are in `en.json` and `vi.json` with the same keys.
- Deleting a sticky uses the canvas remove path. It does not use `ConfirmDeleteDialog`.

## Design Alignment

- Right-click on empty canvas adds the sticky at the click. The side palette and the add-node command list do not include it. Insert before, insert after, and insert on an edge do not offer it.
- The paper is a sticky: a short coloured band, the text on the paper, and no handles or node header.
- Arrange leaves the sticky where it is. A run does not execute it.
