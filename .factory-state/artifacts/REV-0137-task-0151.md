### Non-Blocking

- `config set` calls `Catalog.format` with the setting name. The first version passed that name as `key`, which is already the message-id parameter, and `config set` crashed. The fix passes `setting`. `error.config_missing` uses the same placeholder. Validation after the fix passed.
- The bundled changelog reader keeps the last `## ` heading. A newest-first changelog would report the oldest version. No changelog is shipped in the package yet, so a failed registry check still becomes `unknown`.
- The Docker-socket check runs only when `instance.json` has `sandbox`. A compose file that needs the socket for Code nodes, without that flag, is not reported. The acceptance fixture is the sandbox case, and that one is covered.
- The branch does not contain the chat-rating commits now on `develop`. Rebase onto `origin/develop` before opening the pull request so those commits stay.

## Standards And Architecture Alignment

- DEC-0068 decision 6: `config list` masks names that contain `SECRET`, `PASSWORD`, `TOKEN`, or `KEY`. `--show-secrets` shows the value, including under `--json`. `.env` stays mode `0600`.
- `JWT_SECRET`, `STUDIO_SECRET_KEY`, `DATABASE_URL`, `REDIS_URL`, `STUDIO_ENV`, and `STUDIO_TRUSTED_PROXIES` restart the stack. `STUDIO_PUBLIC_URL` does not.
- Doctor reports the placeholder `dev-secret-change-me`, a missing `STUDIO_SECRET_KEY` with no backup mark, `STUDIO_ENV` other than `production`, a non-https public URL except `localhost` and `127.0.0.1`, missing `STUDIO_TRUSTED_PROXIES` on `full`, a sandbox compose file without `docker.sock`, clock skew above 30 seconds, and an unreachable provider URL. Offline skips that last check and does not print `OPENAI_API_KEY`.
- `status` reads `data.version`, `database`, and `run_bus` from the health envelope. It does not open the database.
- No new dependency and no API change.
