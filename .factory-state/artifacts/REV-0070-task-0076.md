## Findings

### Non-Blocking

- **Fields come from the saved graph.** The dialog reads `GET /api/workflows/{wid}`, so it offers exactly the
  fields the server accepts. A field added but not saved is not listed until Save.
- **The sample uses "@bot".** The studio does not know the Slack bot's display name, so the sample shows a neutral
  `@bot`.
- **History loads when the editor opens.** A chat run started while the editor is open shows after a reload or the
  next run, as for API and schedule runs.
- **Checked visually** in the light and dark themes at 900 px. The dialog is shadcn Dialog, Select, Switch, Input,
  Alert and Badge, with theme tokens only (`text-warning`, `border-warning`, `variant="warning"`).
