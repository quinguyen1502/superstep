### Non-Blocking

- **The hint and the "missing" message do not overlap.** The hint shows only when no knowledge base is chosen
  (`!kb`); the existing "no longer exists" message shows only when the chosen one is gone.
- **The template errors show once.** The editor reads them from router state, lists them, and replaces the history
  entry with `state: null`, so a reload does not bring them back. The e2e test reloads to check this.
- **The listed errors are the same strings a save shows, so they stay English.** They come from the `use` endpoint,
  which already returned them; the editor puts them in the same Run panel list (`#validation-errors`). In vi the
  title is "1 lỗi cần sửa", but the item reads "choose a knowledge base" (the e2e test checks both). This predates
  the task: validator messages from the backend are not translated anywhere in the editor.
- **With no knowledge base at all, the Agent tool shows two lines:** the red hint and the grey "No knowledge base
  yet. Create one". Both are true, and the second has the link, so this is acceptable.
- **Plural keys.** `errorsBadge` / `errorsTitle` now have `_one` and `_other` in both locales. Vietnamese has no
  plural form, so the vi strings are the same for both.
