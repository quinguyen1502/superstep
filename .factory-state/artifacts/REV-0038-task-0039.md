## Findings

### Blocking

### Non-Blocking

- The address check moved from `services/webhooks.py` to `core/net.py` unchanged, plus `ValueError` (an invalid port) in the refused cases. Webhooks re-export the two names so existing tests and callers keep working; MCP imports `core.net` directly.
- The HTTP Tool node now uses its own `httpx.Client` per call instead of `httpx.request`. `user:pass@` in the URL is sent as basic auth, because the pinned URL drops the userinfo.
- An HTTP Tool workflow that called `localhost` or a private host now fails with `HTTP_TOOL_URL_BLOCKED` until the server sets `STUDIO_HTTP_TOOL_ALLOW_PRIVATE=1`. That is the intended change; README and `.env.example` say so.
- `pick_branch` keeps exact and case-insensitive matches first. The old substring fallback is now a whole-word match where the longest label wins. A value such as `generally` no longer matches the label `general`.
- With no `STUDIO_CORS_ORIGINS`, production no longer adds CORS headers. Compose serves the UI and the API from one origin through nginx, so it is unaffected. A setup that called the API from another origin must set the variable.
- Editor header: the right grid column is `minmax(min-content,1fr)`, so its icons never overflow onto the centre actions. The info badges (`#header-info`) use `contain: inline-size` and clip. At 1280px with pending-run and notification counts, `⋯` and Cancel are clickable.
- Settings navigation moved to `sections.ts` so the command palette does not import the Settings page. Adding a section now needs an entry in `SECTIONS` and in `COMPONENTS`; the `Record<SectionId, …>` type makes a missing component a type error.
- 46 React hook oxlint warnings remain. They are out of scope (REQ-0027) and belong with the Editor split.
