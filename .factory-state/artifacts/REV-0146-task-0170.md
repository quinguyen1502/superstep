## Findings

### Blocking

### Non-Blocking

- A cancelled case does not get a JUnit `failure` element. The process still exits 1 because the suite status is not `done`. A CI job that ignores the exit code and reads only the XML can count that suite as green.
- An empty case list is `NO_TESTS` and does not POST. The run route's empty-suite error is HTTP 404 `TEST_NOT_FOUND`, which `phase2=True` would report as `SERVER_TOO_OLD`.
