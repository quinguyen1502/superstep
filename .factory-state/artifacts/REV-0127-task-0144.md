### Fixed During Review

- **The page screenshot showed a mock answer.** After a message, the page showed little more than the mock model
  echoing "Answer: Answer: …". The capture now takes the page's first view instead, with the intro and two suggested
  messages, which is what a visitor sees and what the section describes.

### Non-Blocking

- **What the guide promises matches the code:**
  - the default limits are 10 and 30 per minute and 500 per day;
  - a signed-in user without the run right can chat;
  - runs use the owner's resources;
  - the demo publishes nothing;
  - unpublishing shows "not available";
  - visitor chats are read-only with every step;
  - `data-position` and `data-open` work;
  - the host site can read the widget token, which the guide states plainly so builders embed the bubble only on sites
    they trust;
  - a plain frame may lose its history in Safari.
- **Wording.** The vi pages follow the glossary rows added in TASK-0142 and TASK-0143: trang công khai, địa chỉ
  trang, lời giới thiệu, tin nhắn gợi ý, Khách, nhúng, frame, bong bóng chat.
- **The comparison pages.** Only the visual builders page names services, so only it changes. The agent frameworks
  page says nothing about chat front ends.
- **Release.** The 0.9.0 bump (#184, a draft) still lists only REQ-0073 and TASK-0132. Its contents and CHANGELOG
  heading need updating once this chain is merged.
